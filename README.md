# tech.soyoren.qdhook

![LSPosed](https://img.shields.io/badge/LSPosed-module-blue)
![LibXposed API](https://img.shields.io/badge/LibXposed_API-102-blue)
![版本](https://img.shields.io/badge/版本-26.10.2-green)

基于 **LibXposed API 102**，提供自动签到、跳过激励计划视频和切换系统 WebView 功能，可在起点读书内统一设置。

**当前版本：26.10.2** · **模块包名：`tech.soyoren.qdhook`**

## 下载

前往本仓库的 **Releases** 页面，下载 `QDHook-26.10.2-arm64.apk`。

本仓库仅提供使用说明和 APK 发布，不公开源码。

## 功能

| 功能 | 说明 | 首次安装默认 |
| --- | --- | --- |
| 自动签到 | 登录后打开书架，按原应用流程完成当天签到；已签到时不重复提交 | 关闭 |
| 跳过广告 | 跳过激励计划视频任务，保留原奖励流程 | 开启 |
| 启用系统 WebView | 使用系统 WebView 打开主进程内的网页，可改善福利中心滚动卡顿 | 开启 |

“跳过广告”针对激励计划视频任务。视频跳过及奖励到账已在测试环境验证。自动签到已验证“今日已签到”时不重复提交，新的未签到账号或日期仍待验证。

## 兼容说明

- 需要支持 **LibXposed API 102** 的 LSPosed 环境。
- 适配目标为原包名 **`com.qidian.QDReader`** 的起点读书 **7.9.478**，修改包名的共存版本暂未适配。

- 配置保存在起点读书的私有目录，模块更换包名后可保留已有设置。

## 使用方式

1. 下载并安装模块 APK。
2. 在 LSPosed 中启用 **QDHook**，作用域勾选 **起点读书**。
3. 强行停止起点读书后重新打开。
4. 进入 **设置 → QDHook 模块设置**，调整需要的功能。
5. 点击底部 **保存并重启**，保存配置并重新打开起点。

“保存并重启”默认置灰，任一开关发生改动后亮起；全部改回原值后再次置灰。开关改动后需点击按钮保存，直接返回时可选择继续编辑或放弃更改。

部分 ROM 会提示“起点读书想要打开 QDHook”和“QDHook 想要打开起点读书”，需允许这两个方向的应用拉起。“本次允许”用于当次操作，“始终允许”由系统记住。若拒绝或等待首次确认超过 30 秒，可手动强行停止起点后重新打开，已保存配置仍会生效。


## 常见问题

### 找不到模块设置入口

确认 LSPosed 已启用新版 QDHook、作用域已勾选起点读书，并强行停止起点后重新打开。同时检查起点版本和包名是否在适配范围内。

### “保存并重启”无法点击

当前开关与已保存配置一致时，按钮会置灰。修改任一开关即可启用；如果全部改回原值，按钮会再次禁用。

### 保存后没有自动重新打开起点

检查 ROM 是否弹出应用拉起确认，并允许 QDHook 与起点互相打开。若重启未完成，手动强行停止起点后重新打开即可读取已保存配置。

### 自动签到没有触发

该功能默认关闭，需要手动开启并保存。请确认已登录、打开书架，并且当天尚未签到；当天已签到时会跳过。新的未签到事务目前仍待验证，遇到未触发时可使用应用原有签到入口。

### 系统 WebView 开关已修改，但网页内核没有变化

内核切换需要保存配置并重启起点进程。重新进入福利页面后，可在模块设置中查看“本次网页内核”；尚未打开网页时，这里会显示“尚未打开网页”。关闭系统 WebView 后，恢复起点自身的内核选择。
